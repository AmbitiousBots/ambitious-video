# Security

## Reporting a vulnerability

Report a security vulnerability in private. Use GitHub private vulnerability reporting for this repository:

https://github.com/AmbitiousBots/ambitious-video/security/advisories/new

If that page is not available, contact a maintainer through GitHub and say that the report is sensitive. Do not include the details until the maintainer gives you a private place to send them.

Do not open a public issue for a security problem. Do not include a secret, an API key, or a copy of one.

We will acknowledge the report, work on a fix, and credit you if you want to be named. Please give us time to fix the issue before you write about it in public.

Reports about community behavior belong with [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md). Use the same private channel.

## Supported versions

Security fixes are made on the latest release of this repository.
